## Objetivo da aula

Instruir os alunos sobre o que fazer quando a base vier poluida. Tratar colunas, mudar tipos de dados, separar colunas, entre outros

## Tópicos

- Power Query

## Metodologia e sugestões

A aula gira em torno da limpeza do audible_uncleaned dataset, um dataset sobre ebooks com dados bastante mal formatados.

No arquivo "ebooks tratado" é possível ver alguns tratamentos legais para demonstrar o uso do Power Query nesta aula

Como exercícios, pode-se pedir algumas análises do movies.csv após tratamento. Como desafio é possível passar o exercício 2, que já é um exercício aplicado a negócio e que exigirá bastante tratamento dos dados.

No exercício 2, caso os alunos tenham tido contato com python no curso, é possível recapitular a limpeza de dados com python na aula seguinte, usando o notebook Data science jobs

## Arquivos complementares

O arquivo ebooks_tratado, mostra o tratamento do dataset audible, com o passo a passo de algumas transformações no power query.
