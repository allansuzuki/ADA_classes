# Publicação no Power BI
 
Chegamos à última etapa e com o dashboard de vendas pronto seguimos para a publicação dele. Com isso levamos o dashboard da versão desktop para a versão web, podendo ser compartilhado. Agora veremos os detalhes para a publicação. Só um detalhe importante é atentar para os custos da solução web do Power BI, que podem ser conferidos na página https://powerbi.microsoft.com/pt-br/pricing/.
 
## Passos para a publicação no Power BI
 
Na página inicial temos um botão de publicar em destaque na **Figura 1**. É através dele que levamos o dashboard criado no Power BI Desktop para o serviço online da Microsoft.
