## Avaliação por rubrica

As habilidades a serem avaliadas no módulo de Power BI:

- Conexão com fontes de dados

- Data Discovery

- Tratamento dos dados com DAX

- Calculo de métricas

- Escolha adequada de visualizações

- Estilização de visualizações

- Validação de hipóteses

- Uso de granularidade adequada para os dados escolhidos

- Publicação dos dados
